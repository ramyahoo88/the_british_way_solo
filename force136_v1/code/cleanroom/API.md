# Engine API notes for the clean-room implementation

- `engine.py` is the game executor. Board: `self.board[space]` dict with keys troops, police, red_u, red_a (MPAJA guerrillas Underground/Active), blue_u, blue_a (non-MPAJA), force136 (0/1+), kempeitai, camp (bool), cache (bool), new_village, opposition (bool), terror, intel (None = concealed, else revealed value), population.
- Spaces: `ORDER` (= map order), `PROV` (8 Provinces), `POP`, `ADJ`, `MOUNTAIN`. Railways: `EDGES` keys; `self.rail_adj(r)` = spaces adjacent to railway r; `self.sabotage[r]` = number of Sabotage markers.
- Helpers: `gs(v)` guerrillas, `ug(v)` underground, `red(v)`, `blue(v)`, `cubes(v)`, `clamp`, `self.available(kind)` for 'red','blue','cache','camp','force136','police'; `self.activate(s,color=None)` (red first if None); `self.add_camp(s)` (engine handles "Camp from the map"); `self.donor_ok(s,n)`; `self.cache_bonus(s)` = Caches in and adjacent to s; `self.gather_targets(anchor, allow_adj)` = spaces with a concealed chit and an Underground guerrilla that a Gather from anchor can reveal; `self.die(tag,space)` rolls (tag 'Ambush' for Ambush); `self.cleanup()`; `self.clone()` gives a preview copy (dice fixed, concealed chits count as value 1) for "would" tests; `self.special(name)` calls supply/gather/raid; `self.rail(region)` performs Sabotage in every F136 space using your `rail_choice`.
- `self.cap` = executed capabilities {card number: 'U' British side / 'S' Japanese side}. `self.zipper` in {0,6,12,18,20}. `self.chosen` = boxes already taken this card ({'J': box}); `free` lists the free boxes ('Limited','Event','Op & SA'). `BOXES` = left-to-right order.
- Engine calls into your British methods: bot_turn(free); contact(task=None, hold=False); train(locations=None, reserve_cache_donors=False); strike(locations=None, color=None, bose=False, extra=True) and strike_option(s, force_color=None, bose=False) [returns None or a tuple] and strike_rank(s,...); rail_choice(s, region='C', stack=False, eligible=None) [for stack=True delegate to FastGame.rail_choice]; gather(); supply(); raid(); icon(j) [handle Mobilize (MOBILIZE set) and Kill Traitors (KILL set); delegate the rest to FastGame.icon]; placement_rank(s) [used for Mobilize placement order when red runs short].
- The engine already implements three British choices with its own code: forced losses (`lose_guerrilla(..., british=True)`), Camp from the map (`add_camp`), Zipper Cache removal (`move_zipper`). Do not override them; instead check whether the engine code matches the printed rules and report any difference.
- In bot_turn set `self.chosen['B']=box`, execute, and set `self.last_plan=dict(goal=..., box=..., op=..., sa=...)` with op in CONTACT, TRAIN, AMBUSH, SABOTAGE, PASS and sa in GATHER, SUPPLY, RAID or None.
